# ADR-0003：MySQL 持久化异步任务

- 状态：已接受
- 日期：2026-08-10

## 背景

四类大文件导入、导出、AI 分析和 Word/PDF 生成可能持续数秒到数分钟。同步 HTTP 会超时，而首期规模与预算不支持无依据地引入 Redis 或外部消息队列。

## 决策

首期使用 MySQL `business_task` 表作为持久任务队列。API 创建任务后返回 `202 Accepted` 和状态资源位置；独立 Java worker 通过租约领取任务，使用业务幂等键防重，记录重试次数和最终失败原因。

## 结果

- 服务重启后任务可恢复，优于进程内后台线程。
- 运维组件更少，符合 Windows 单机试运行目标。
- 数据库压力和任务吞吐达到明确阈值后，才评估外部 MQ；迁移时保持任务状态机和幂等契约不变。
