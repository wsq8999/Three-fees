# ADR-0001：Java 模块化单体 + 无状态 AI Sidecar

- 状态：已接受
- 日期：2026-08-10

## 背景

业务需要稳定的用户、地市权限、月度导入、审计、报告、任务和审计日志，同时需要复用 AI DEMO 中的文档解析和结构化生成思路。DEMO 使用 FastAPI、LangGraph 和 PostgreSQL，包含业务数据库实现、真实材料和敏感配置，不适合直接并入 Java/MySQL 主系统。

## 决策

采用 Java 21 / Spring Boot 模块化单体作为公开 API 和唯一业务事实源；采用独立、无状态、仅内网可见的 Python sidecar 提供原子 AI 能力。Python 不访问 MySQL，不保存用户、任务或报告状态。

Java 持久化工作流、幂等、重试、人工中断和审计；Python 请求和响应使用版本化 JSON Schema。生产时 AI 仅监听回环地址并使用内部服务令牌。

## 结果

- 获得清晰的数据所有权、权限边界和可恢复任务状态。
- 保留 Python AI 生态优势，又不让第二套业务数据库造成数据漂移。
- 首期多一个本机服务进程，但由 WinSW 统一管理，成本仍低于拆分微服务和外部队列。
- 未来只有当吞吐或团队边界提供事实证据时才进一步拆分。
