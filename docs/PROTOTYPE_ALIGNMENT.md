# 原型对齐清单

本文档用于约束前端页面实现。所有页面必须以《智能物业管理系统需求文档.docx》中的原型图和正文为准，不允许用通用后台模板替代。

## 全局框架

- 系统名称：智能物业管理系统。
- 菜单：工作台、报账点管理、稽核报告管理/生成报告、稽核报告管理/历史报告、标杆规则管理、用户管理。
- 页面框架：左侧导航 + 顶部面包屑 + 主内容区。
- 主视觉：白色卡片、浅灰背景、红色主按钮/选中态，整体必须接近需求文档原型，不做老旧后台风格。
- 业务命名：统一使用“报账点”，不得写成“计费点”。

## 业务流程约束

1. 首次为空库时，页面显示正确空态，但结构不能缺失。
2. 数据导入不让人工填写账期；账期来自导入文件中的自然月数据。
3. 四类数据完整后形成当前账期，并触发稽核计算。
4. 只有“超标 + 未生成正式报告”的报账点进入工作台和生成报告任务。
5. 点击“分析图片”才出现 AI 助手；AI 输出必须回显到报告区，人工确认后生成并下载 Word。
